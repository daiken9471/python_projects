# python_projects
examples of Python projects I've worked on.

Pixel.py creates pixel objects as a tuple containing r,g,b elements with either three 0-255 elements or a 6-digit hexadecimal value. 
PPM_Image.py imports an existing .PPM file or lets you build your own canvas from scratch. Then allows you to edit the pixels within and save it to a new .ppm file.
Menu.py receives arguments and restructures them into a readable menu for a user to select options from.
App.py has simple functions that it sends to Menu so that when a use selects an option then those functions will execute PPM_Image and Pixel functions to build and edit an image.
